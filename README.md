# GrafGit — GitHub Contribution Studio

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**GrafGit** — це автономний десктопний інженерний інструмент для створення піксель-арту та написів на графіку активності GitHub (Contribution Graph) з можливістю сканування поточної історії комітів, малювання по різних роках та безпечного очищення.

Працює повністю нативно на Python без важких веб-фреймворків (Electron тощо), споживає мінімум ресурсів (~30 МБ ОЗП) і стартує миттєво.

## Можливості

* **Студія компонування (робота з кількома об'єктами одночасно):**
  * Додавання на полотно довільної кількості зображень, тексту та готових шаблонів одночасно (`+ Зображення`, `+ Текст`, `+ Шаблон`: Серце, Галочка, Хвиля, Шахівниця).
  * **Швидке дублювання шарів:** Кнопка `Дублювати` клонує обраний елемент зі зміщенням по осі X.
  * Усі елементи відображаються у списку шарів зліва з можливістю індивідуального редагування.
  * **Плавні повзунки переміщення:**
    * **Зсув X (тиждень 0..52):** плавний повзунок дозволяє переміщувати будь-який елемент (картинку, текст чи шаблон) вздовж року з живим оновленням на сітці.
    * **Зсув Y (рядок 0..6):** плавний повзунок для вертикального вирівнювання.
  * **Кнопки швидкого 2D-зсуву:** Стрілки `◀ Вліво`, `Вправо ▶`, `▲ Вгору`, `▼ Вниз` у вкладках «Шаблони» та «Пензель».
  * **Масштабування поля малювання (Zoom):**
    * Кнопки `−` / `+` та швидкі пресети (`12px`, `15px`, `18px`, `22px`) змінюють розмір клітинки з автоматичною підтримкою горизонтального скролу при великому збільшенні.
  * **Гнучкі роздільники віконець (PanedWindow):**
    * Можливість перетягувати мишкою межі між інструментами та журналом Git Output, підлаштовуючи робочий простір.
  * **Динамічний текст у реальному часі:**
    * Текст на сітці оновлюється безпосередньо під час введення літер у полі.
  * **Чутливість виділення для зображень:**
    * Окремий повзунок чутливості (0.2x – 3.0x), інверсія чорне/біле та висота для кожного зображення окремо.
  * **Видалення елементів:** Кнопка `Видалити` або гаряча клавіша прибирає непотрібний елемент без впливу на інші.
* **Експорт у PNG (High-Res):**
  * Кнопка `Експорт PNG` у верхній панелі експортує графік у 2x PNG-зображення з темною темою GitHub, назвами місяців, днів та легендою.
* **Налаштування ваги рівнів (комітів на клітинку):**
  * Кнопка `Рівні...` дозволяє задати точну кількість комітів для рівнів 1, 2, 3 і 4 (наприклад, 1, 3, 6, 25), якщо у вашому профілі GitHub вже є дні з високою активністю.
* **Копіювання між роками:**
  * Кнопка `Копіювати в рік...` в один клік копіює весь арт та всі шари з поточного року в будь-який інший (наприклад, з 2024 у 2025).
* **Візуальний прогрес-бар створення комітів:**
  * Індикатор виконання (`ttk.Progressbar`) з відсотками та лічильником (`45 / 120 (37%)`), а також тимчасове блокування кнопок від випадкових повторних натискань.
* **Повноцінний Undo / Redo (Ctrl+Z / Ctrl+Y):**
  * Будь-яка дія (переміщення повзунка, редагування тексту, додавання картинки, ручне малювання, очищення) скасовується за допомогою `Ctrl+Z` або кнопки «Відмінити» у верхній панелі.
* **Чітке відображення при масштабуванні Windows (125%, 150%, 4K):**
  * Вбудована підтримка Windows Per-Monitor DPI Awareness V2 усуває розмитість шрифтів та пікселів при будь-якому масштабуванні системи.
* **Точна геометрія календаря GitHub:**
  * 53–54 тижні × 7 днів (Sunday-first), врахування високосних років.
  * Назви місяців (Jan..Dec) та днів (Mon, Wed, Fri), ідентично інтерфейсу GitHub.
* **Відображення поточної активності (Scan Git):**
  * Кнопка `Сканувати Git` зчитує реальну історію вашого репозиторію за обраний рік та наносить поточні коміти на сітку.
* **Підтримка декількох років:**
  * Кнопки перемикання років (`2023`, `2024`, `2025`, `2026` тощо).
  * Малюнок та елементи для кожного року зберігаються незалежно.
* **Безпека та Git-рушій:**
  * **Ізоляція:** Усі коміти графіка вносяться в окремий технічний файл `.grafgit/art.dat`, не чіпаючи вихідний код проекту.
  * **Врахування таймзони:** Точний розрахунок локального зміщення часового поясу (Timezone offset), щоб дата коміту на GitHub збігалася з клітинкою.
  * **Dry Run (Попередній перегляд):** Розрахунок кількості комітів і дат без запису в Git.
  * **Безпечний відкат (Rollback) + Force Push:** Перед початком малювання програма автоматично зберігає точку відкату (`pre_art_head.txt`), дозволяючи в один клік повернути локальний репозиторій до початкового стану (навіть якщо репозиторій був порожнім) і одразу пропонує виконати `git push --force` для очищення GitHub.
  * **Збереження проектів:** Формат `.grafgit` (JSON) зберігає стан шарів та налаштувань.

## Швидкий запуск

### 1. Вимоги
* Python 3.10+ (перевірено на Python 3.13)
* Встановлений `git`
* Бібліотека `Pillow`:
  ```bash
  pip install pillow
  ```

### 2. Запуск програми
У корені репозиторію виконайте:
```bash
python run.py
```
Також можна передати шлях до будь-якого іншого Git-репозиторію:
```bash
python run.py "C:\path\to\your\project"
```

## Робота з композитором елементів

1. Натисніть **`+ Зображення`** та оберіть файл. Зображення з'явиться на сітці.
2. Рухайте повзунок **«Зсув X (тиждень)»** — елемент плавно переміщується по календарю.
3. Натисніть **`+ Текст`** — з'явиться текстовий блок. Введіть потрібне слово, і воно миттєво з'явиться на полі.
4. Натисніть **`Дублювати`**, якщо потрібно швидко створити копію поточного напису або зображення.
5. Перемикайтеся між елементами в списку зліва та налаштовуйте кожен окремо.
6. Для скасування останньої дії натисніть **`Ctrl+Z`**.

## Часті запитання (FAQ)

### Як видалити графіку, якщо я передумав?
* **Варіант 1 (з програми):** Натисніть кнопку **`Скинути історію`** в програмі — вона поверне локальну історію до стану перед малюванням і запропонує виконати force push на GitHub.
* **Варіант 2 (через GitHub):** Якщо ви малювали в окремому технічному репозиторії — просто видаліть цей репозиторій у налаштуваннях GitHub (`Settings -> Delete this repository`). Протягом кількох хвилин усі квадратики зникнуть з вашого графіка активності.

### Чи видно графіку, якщо репозиторій приватний (Private)?
* **Так.** На сторінці профілю GitHub над графіком активності відкрийте **`Contribution settings`** і увімкніть **`Private contributions`**.
* Тоді коміти будуть відображатися на графіку для всіх відвідувачів без розкриття назви репозиторію чи вмісту коду.
